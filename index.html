ไฟล์จะเข้าโฟลเดอร์ ปีการศึกษา xxxx → ภาคเรียนที่ x และลงชีต ผลงาน_xxxx_x อัตโนมัติ

👥 สมาชิกในงานชิ้นนี้ งานเดี่ยวไม่ต้องกดเพิ่ม

งานกลุ่ม: เลือกชั้น+ชื่อทีละคนแล้วกด “＋ เพิ่มคนนี้” อัปโหลดไฟล์ครั้งเดียว ระบบแตกแถวรายคนให้ (กรอง/เช็คตามชื่อได้เหมือนงานเดี่ยว)

ส่งงานอย่างไร?

  1. เลือก ปีการศึกษา / ภาคเรียน ให้ตรงเทอมปัจจุบัน
  2. กรอกชื่อ-สกุล / วิชา / ประเภทให้ครบ
  3. เลือก ภาพ / PDF / ลิงก์
  4. กดส่ง → ไฟล์เข้า Drive โฟลเดอร์ปี/เทอม/วิชาอัตโนมัติ
  5. ข้อมูลลงชีต ผลงาน_ปี_เทอม ทันที สถานะ “รอตรวจ”
  6. ดูผลงานได้ที่หน้า Padlet (กรองตามปี/เทอมได้)

เข้าสู่ระบบ

✅ ล็อกอินแล้ว () 📊 เปิด Sheet (Admin) 📁 เปิด Drive (Admin)

📅 แท็บชีตแยกตามเทอม

ชีต ผลงาน_ปี_เทอม ถูกสร้างอัตโนมัติเมื่อมีการส่งงานเทอมนั้นครั้งแรก • งานเก่าก่อนแยกเทอมอยู่ในแท็บ “ผลงาน”

🩹 งานที่ยังไม่มีปี: แตะเฉพาะแถวที่ปีว่าง • แถวที่มีปีแล้วไม่โดนเปลี่ยน

📚 วิชา

เพิ่ม/แก้ไข/ลบ บันทึกลงชีต “วิชา” แล้วดึงมาใช้ทุกหน้า • กำกับห้องได้ (ว่าง = ทุกห้อง)

👦 นักเรียน

👩‍🏫 บัญชีครู

เฉพาะ Admin เพิ่ม/ลบได้ • ครูล็อกอินช่องเดิม ตรวจงานได้เฉพาะวิชาที่กำหนด (ลบ/จัดการระบบไม่ได้) • 1 วิชา = 1 ครูเท่านั้น วิชาที่มีครูแล้วจะติ๊กไม่ได้ • รหัสเก็บเป็นข้อความธรรมดาในชีต “ครู” อย่าใช้รหัสเดียวกับอีเมล

วิชาที่สอน (เลือกชั้นเพื่อกรอง แล้วติ๊กวิชา — วิชาที่มีครูแล้วติ๊กไม่ได้)

👩‍🏫 ล็อกอินครู — ตรวจ/ส่งได้เฉพาะวิชา: (เมนูจัดการวิชา/นักเรียน/บัญชีครู/ปุ่มลบ เป็นของ Admin เท่านั้น)
